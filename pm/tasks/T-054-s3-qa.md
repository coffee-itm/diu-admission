## Checklist
1. Register a new candidate in the browser against the real API; confirm the account appears in Mongo with an `$argon2id$` hash and no plaintext anywhere.
2. Log in, reload the page: the session survives, with **no token in `localStorage`** (check DevTools → Application).
3. Leave the tab open past the 15-minute access-token TTL, then act: the silent refresh works and the user is not kicked out.
4. Log out, then log in as a different user on the same browser: no trace of the first user's test or anti-cheat state (FR-AUTH-04).
5. Wrong password ×5 → 429, and the message never reveals whether the email exists.
6. Replay a rotated refresh cookie with curl → 401, and every token in that family is revoked.
7. Call an `/admin/*` endpoint with a candidate token → 403; with no token → 401.
8. Try to register with `"role":"admin"` in the body → the created user is still a candidate.
9. Try to disable the last admin → 409.
10. `VITE_USE_MOCKS=true` still runs the whole demo offline with no backend.
11. `pnpm test:coverage` prints all three packages; CI is green with zero annotations.
12. Re-run the S2 regressions that auth could have broken: the test engine start→submit→result flow, and the merit-list filter.
