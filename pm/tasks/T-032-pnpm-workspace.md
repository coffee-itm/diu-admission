## Goal
The repo becomes a pnpm workspace: the frontend stays at the root, and there are two new packages, `packages/shared` (`@diu/shared`) and `server` (`@diu/server`). Root scripts can run the frontend, the server, or every package's tests. Nothing in `src/` moves in this card.

## Context to read
- `context/16-backend-architecture.md` §1: the layout and the exact root scripts
- `pnpm-workspace.yaml` (keep `allowBuilds`), `package.json`, `vite.config.js` (the `test` block)

## Files
- `pnpm-workspace.yaml` (modify): `packages: ['.', 'server', 'packages/*']`, and keep `allowBuilds`.
- `packages/shared/package.json` (create): `name: @diu/shared`, `private: true`, `type: module`, `exports: { ".": "./index.js", "./*": "./*.js" }`, `scripts.test: "vitest run --passWithNoTests"` (plain `vitest run` exits 1 with no test files, which would break AC3), and `zod` as a dependency at the root's version.
- `packages/shared/index.js` (create): `export {};` placeholder with a one-line comment.
- `server/package.json` (create): `name: @diu/server`, `private: true`, `type: module`, `engines.node: ">=22"`, `dependencies: { "@diu/shared": "workspace:*" }`, `scripts.test: "vitest run --passWithNoTests"`, and placeholder `dev`/`start` scripts (`node src/server.js`; the file comes in T-036).
- `package.json` (modify): add `dev:server`, `dev:all`, `test:all`, `seed` exactly as in 16 §1, `engines.node: ">=22"`, and `"@diu/shared": "workspace:*"` in dependencies.
- `vite.config.js` (modify): `test.include: ['src/**/*.test.{js,jsx}']`, so the root `vitest` never picks up `server/` or `packages/` tests.
- `pnpm-lock.yaml`: regenerated by `pnpm install`.
