## Procedure
1. `pnpm install --frozen-lockfile && pnpm lint && pnpm test && pnpm build` — record the counts.
2. `pnpm dev` and run the smoke script (in Claude Code the `agent-browser` skill can drive the browser; otherwise do it manually and record the results):

   - Try Start again → blocked ("already taken"). Log out, log in as `demo@candidate.com` → no leftover session.
   - **J2 Admin:** `admin@diu.edu` → dashboard (names, counts) → Candidates (new candidate listed) → detail (loads, security section shows the 2 tab switches) → Merit List (new candidate, CSV export opens) → Question Bank (CSV import of the template) → Exam Config (change time to 60 → candidate dashboard shows 60) → Analytics (trend shows real dates).
   - Check the browser console for errors on every page.
3. Write the results into this card's "Agent log" as a checklist with ✅/❌. For every ❌, open a new escalation in `pm/ESCALATIONS.md` (don't fix code).
