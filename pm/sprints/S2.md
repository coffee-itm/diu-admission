## Risks
| Risk | Mitigation |
|:--|:--|
| First sprint using the free model as builder: quality unknown | Small, tightly specified free-ok cards. The coordinator runs the gate itself and Haiku reviews. First-pass approval rate is tracked for the retro |
| T-033 move breaks one of ~43 import sites | Re-export shims in `src/lib/*`. Imports are rewritten later, as files are touched |
| Root vitest picks up server/shared tests (wrong env) | `test.include` limited to `src/**` (T-032) |
| mongodb-memory-server binary download is slow or flaky in CI | Cache `~/.cache/mongodb-binaries` (T-038); long hook timeout (T-037) |
| Builder edits the board or another lane's files | Playbook rule: own row only; the coordinator commits the board |
